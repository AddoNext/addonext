A large library of Elementor widgets plus site-wide extensions: content and layout blocks, creative effects, marketing tools, data visualizations, and WooCommerce components—all manageable from the Elementrify admin.

== Description ==

Elementrify extends the Elementor page builder with dozens of widgets grouped into clear categories, optional extensions that apply across your site, and a dedicated settings area to enable only what you need.

**Content widgets**

Accordion, Advanced Google Map, Advanced Heading, Advanced Tabs, Animated Text, Badge, Blockquote, Button, Code Snippet, Content Toggle, Divider, Dropcap, Hero Banner, Hero Slider, Highlight, Icon Box, Icon List, Image Box, Modal Popup, Navigation Menu, News Ticker, Off Canvas Content, Smart Post List, Spacer, Table of Contents, Text Editor, Video Gallery, and Video Player.

**Creative widgets**

Animated Counter, Animated Gradient, Animated SVG, Before & After Slider, Bento Grid, Circular Progress, Countdown Timer, Dual Heading, Flip Box, Image Carousel, Image Gallery, Image Hotspot, Lottie Animation, Progress Bar, Star Rating, Timeline, and Tooltip.

**Marketing widgets**

Author Box, Banner, Call to Action, Comparison Table, Contact Form, Contact Form 7 Styler, Instagram Feed, Logo Showcase, Notice Board, Price List, Pricing Table, Promo Box, Social Share, Subscribe Form, Team Members, Testimonials, USP Items, and Twitter Feed.

**Data and chart widgets**

Advanced Analytics, Area Chart, Bar Chart, Data Table, Donut Chart, Line Chart, Pie Chart, and Radar Chart.

**WooCommerce widgets** (when WooCommerce is active)

Add to Cart, Mini Cart, Product Carousel, Product Categories, Product Filter, Product Grid, Product Image, Product Tabs, WooCommerce Checkout, Customer Dashboard, and Thank You page layouts.

**Extensions**

Optional features such as smooth scrolling, layout duplication, custom CSS and JavaScript injection, a reading progress bar, scroll-to-top control, particle backgrounds, and moving circle effects—toggle them on or off from the plugin dashboard.

**Requirements**

* WordPress 6.0 or newer
* PHP 7.4 or newer
* Elementor (free or Pro) must be installed and active

WooCommerce-related widgets are available when WooCommerce is installed. Some Contact Form 7 styling options need Contact Form 7. A Pro license may be required for certain advanced widgets or capabilities; see the plugin’s license screen for details.

== Installation ==

1. Upload the `elementrify` folder to `/wp-content/plugins/`, or install the ZIP from the Plugins → Add New screen.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Ensure **Elementor** is installed and activated.
4. Open **Elementrify** in the admin menu to configure active widgets and extensions, then edit any page with Elementor and find **Elementrify** widgets in the panel.

== Frequently Asked Questions ==

= Does Elementrify work without Elementor? =

No. Elementrify registers widgets for Elementor. Install and activate Elementor first.

= Do I need WooCommerce? =

Only if you want to use the WooCommerce-specific widgets. All other widgets work on standard sites.

= Where do I enable or disable individual widgets? =

Use the Elementrify admin screens to control which widgets and extensions are active for your site.

= Is Elementor Pro required? =

No. Elementrify is built for the Elementor editor; Elementor Pro is optional unless your own layout relies on Pro-only Elementor features.
